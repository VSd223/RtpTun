## 🌟 Что нового в версии 1.3.4 (Changelog)

### 🎨 1. Новый дизайн и визуальное оформление
- **Новая иконка приложения:** Добавлена современная адаптивная иконка (Adaptive Icon) для Android 8.0+.
- **Превью тем:** На экране параметров добавлены компактные мини-карточки с закругленными углами и цветовыми превью для быстрого переключения палитр (*Индиго, Cyberpunk, Amoled Black, Лес, Espresso*).
- **Пружинные анимации (Spring Physics):** Плавное переключение вкладок и нижней панели навигации с масштабированием иконки.

### ⚙️ 2. Кардинально улучшенный экран «Параметры и обход» (`AntiBlockTab`)
- **Удобный выпадающий список DNS:** Вместо неудобного списка из 14 радиокнопок теперь используется элегантный селектор (`ExposedDropdownMenu`) для выбора DoH или UDP DNS.
- **Интерактивные карточки-переключатели (Switch Cards):** Тумблеры теперь кликабельны по всей площади карточки.
- **Режимы обхода (Звонок / Капча):** Добавлено интуитивное разделение на **📞 Звонок (Авто по умолчанию)** и **🧩 Капча (с ручным выбором методов `wv` / `rjs`)**.
- **Безупречная контрастность:** Исправлены все проблемы с видимостью текста при переключении тем и темных/AMOLED режимов.

### 🚀 3. Стабильность и сетевой стек
- **Universal Release APK:** Настроена сборка единого подписанного **`app-universal-release.apk`**, поддерживающего все процессоры (`arm64-v8a`, `armeabi-v7a`, `x86_64`).
- **Гарантированный запуск (`forceStart`):** Устранены сбросы соединения на старте — VPN-интерфейс теперь запускается принудительно и стабильно.
- **Умный фон пинга:** Убран назойливый полноэкранный диалог замера задержки; пинг теперь измеряется в фоне, а при старте VPN все активные замеры автоматически отменяются.
- **Авто-возврат на главную:** При успешном установлении соединения с VPN приложение автоматически возвращает вас на главный экран.
- **Яндекс DNS по умолчанию:** Отключено автоматическое переключение на DNS оператора связи.

## 🛠️ Сборка из исходного кода

### Требования
* **JDK:** OpenJDK 17+
* **Android SDK:** API Level 35 (Build-tools 35.0.0)
* **Android NDK:** 26.1+
* **Go Compiler:** 1.22+

### Пошаговая сборка

```bash
# 1. Клонирование репозитория
git clone --recursive https://github.com/your-username/rtptun-android.git
cd rtptun-android

# 2. Сборка нативного Go-модуля
cd core
make build-android
cd ..

# 3. Сборка релизного APK
./gradlew assembleRelease
```
> **Готовый универсальный установочный пакет:** `app/build/outputs/apk/release/app-universal-release.apk`

## 📋 Формат конфигурации и схемы импорта

### Структура конфигурационной строки
```text
host|port|password|hashes|name|country|workers|expire_unix
```

| Поле | Тип | Описание | Пример |
| :--- | :--- | :--- | :--- |
| `host` | String | IP-адрес или домен узла | `154.86.119.116` |
| `port` | String | Порт сервиса | `56000` |
| `password` | String | Ключ аутентификации | `open_secret_2026` |
| `hashes` | String | Сессионные хэши/токены | `nki-wqEB9x...` |
| `name` | String | Отображаемое имя (с авто-флагом) | `Германия [DE]` |
| `country` | String | ISO-код страны | `DE` |
| `workers` | Int | Количество потоков | `18` |
| `expire_unix` | Long | Timestamp срока действия | `1787491200` |

### Поддерживаемые форматы ссылок (URI-схемы):
* `wdtt://<HOST>:<PORT>:0:0:<PASS>:<HASHES>#<NAME>`
* `ptvb://config?name=<NAME>&peer=<HOST>:<PORT>&hashes=<HASHES>&workers=<N>&port=9000&pass=<PASS>`
