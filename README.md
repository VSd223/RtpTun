## 💎 О проекте

**RtpTun** — это высокотехнологичный клиент сетевой инкапсуляции и транспортный фреймворк нового поколения, разработанный для защищённого туннелирования данных и маскировки служебных сетевых сигнатур.

Проект является **Proprietary (закрытым коммерческим решением)**. Сетевая часть базируется на глубоко кастомизированном бинарном ядре Go (`libclient.so`), сопряжённом с нативным драйвером **WireGuard GoBackend**, а пользовательский интерфейс полностью построен на декларативном Jetpack Compose с аппаратным 120 FPS GPU-рендерингом и поддержкой защищённых динамических подписок.

## ⚡ Что нового в обновлении v1.3.0-BETA

* ☁️ **RtpTun Remote Subscription Hub:**
  * Поддержка защищённых облачных подписок по динамическим токенизированным URL (`/sub/<token>`).
  * Разделение серверов: облачные узлы получают метку `☁️ ОБЛАКО`, а созданные вручную и импортированные из буфера — `📋 СВОЙ`.
  * При обновлении подписки удаляются **только** устаревшие облачные серверы, личные конфигурации остаются нетронутыми.
  * Настраиваемый период фоновой синхронизации (6 ч, 12 ч, 24 ч).
* 🔄 **100% Guaranteed Interface Auto-Reconnect:**
  * Бесконечный цикл поднятия системного VPN-интерфейса Android (`tun0`) с адаптивным backoff до подтверждения статуса `Tunnel.State.UP`.
  * Фоновый `Interface Watchdog`, мгновенно восстанавливающий туннель при сбросе сетевых сокетов системой.
* 🎬 **Cinematic GPU Splash Screen:**
  * Видео-заставка на базе `TextureView` с сохранением оригинальных пропорций (`Matrix Fit-Center`) без растягивания.
  * Плавный аппаратный переход (`graphicsLayer` Alpha/Scale + Spring Physics) в главное меню без единого фриза.
* 📊 **Segmented Vector Speedometer:**
  * 7-сегментный векторный спидометр задержки с динамической анимацией стрелки и отображением пинга только при наличии реального отклика (`> 0 ms`).
* 🧭 **Side Dock Dynamic Padding:**
  * Автоматический расчёт отступа контента (`78.dp`) при выборе вертикальной навигационной панели справа (`navPos = right`).
* 🚦 **Offline Handshake Barrier:**
  * Автоматическая блокировка запуска туннеля и оповещение пользователя при выключенном интернете (отсутствии Wi-Fi и сотовых данных).

## 🛠️ Спецификация для разработчиков и панелей подписок

Приложение поддерживает автоматическое получение серверов по защищённым HTTP/HTTPS ссылкам подписки.

### 1. Идентификация клиента (User-Agent)

Приложение отправляет фирменный заголовок при запросе к серверу подписок:

```http
GET /sub/<token> HTTP/1.1
Host: your-domain.com
User-Agent: RTPTun-Core-Engine/2026 (Android; Linux; SecureClient)
X-Client-Platform: RTPTun-Android
Accept: text/plain, application/json, */*
```

* **Для приложений:** Сервер возвращает чистый список зашифрованных строк конфигураций.
* **Для веб-браузеров:** Если запрос открыт человеком без фирменного `User-Agent`, сервер возвращает веб-страницу с карточками серверов и ссылкой подписки.

---

### 2. Структура строки конфигурации

Каждый узел кодируется в унифицированную структуру с разделителем `|`:

```text
host|port|password|hashes|name|country|workers|expire_unix
```

```
┌───────────────┬────────┬─────────────────────────┬──────────────────────────┐
│ Поле          │ Тип    │ Описание                │ Пример                   │
├───────────────┼────────┼─────────────────────────┼──────────────────────────┤
│ host          │ String │ IP-адрес или домен узла │ 154.86.119.116           │
│ port          │ String │ DTLS/UDP порт узла      │ 56000                    │
│ password      │ String │ Секрет подключения      │ secure_pass_2026         │
│ hashes        │ String │ Авторизационные токены  │ nki-wqEB9x...            │
│ name          │ String │ Имя локации             │ Германия [DE]            │
│ country       │ String │ Двухбуквенный ISO-код   │ DE                       │
│ workers       │ Int    │ Количество воркеров     │ 18                       │
│ expire_unix   │ Long   │ Timestamp срока действия│ 1787491200               │
└───────────────┴────────┴─────────────────────────┴──────────────────────────┘
```

Строка шифруется алгоритмом потокового преобразования с блочным Base64-кодированием.

---

### 3. Поддерживаемые URI-схемы

Приложение поддерживает быстрый импорт через системные Intent-фильтры:

* `rtptun://import?data=<ENCRYPTED_BLOB>`
* `ptvb://config?name=<NAME>&peer=<HOST>:<PORT>&hashes=<HASHES>&workers=<N>&port=9000&pass=<PASS>`
* `wdtt://<HOST>:<PORT>:0:0:<PASS>:<HASHES>#<NAME>`

## 📲 Установка и запуск

1. Перейдите в официальный раздел **[Релизы](../../releases)**.
2. Загрузите релизный APK-файл `RtpTun_1.3.0-BETA_Unsigned.apk` (поддерживаются все современные архитектуры процессоров).
3. Разрешите установку из доверенных источников в настройках Android.
4. При первом запуске предоставьте разрешения:
   * **VPN-доступ:** создание системного интерфейса шифрования трафика.
   * **Отображение поверх окон:** необходимо для работы модуля авторизации и проверок безопасности.
   * **Игнорирование оптимизации батареи:** предотвращает принудительное отключение туннеля в фоновом режиме.

### 3. Политика блокировок и санкции
Любая попытка взлома, распространения модифицированных версий, декомпиляции или несанкционированного вмешательства влечёт за собой:

3. **Полный отказ** в технической поддержке и предоставлении обновлений.
